# MAP Growth Simulator

Live (Vercel, git 미연결): https://map-growth-simulator.vercel.app/

## Honesty notes
- 퍼센타일은 기준선 대비 RIT 차이 자체 근사입니다. NWEA 공식 표가 아닙니다.
- Item Uniqueness와 Standard Error는 계산값만 표시하고, 없으면 숨깁니다.
- 문항 수는 G1=10, G2–12=40이 기본이며 랜딩에서 10/40을 고를 수 있습니다.
