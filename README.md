# MAP Growth Simulator

Live (Vercel, git 미연결): https://map-growth-simulator.vercel.app/

K-12 MAP Growth 스타일 연습 시뮬레이터입니다. 공식 NWEA 평가가 아닙니다.

## Honesty notes
- 퍼센타일은 the simulator's own approximate percentile (시뮬레이터 자체 근사 퍼센타일)입니다. 공식 NWEA 퍼센타일 규준이 아닙니다.
- Item Uniqueness는 the ratio of unique item IDs within the set (세트 내 고유 문항 ID 비율)입니다. 값이 없으면 숨깁니다.
- ±RIT 폭은 Internal Simulator Uncertainty (내부 시뮬레이터 불확실성)입니다. 공식 NWEA 표준오차나 보정된 측정오차가 아니며, 정보량이 없으면 숨깁니다.
- 문항 수는 G1=10, G2–12=40이 기본이며 랜딩에서 10/40을 고를 수 있습니다.

## Post-report practice
약점 skillId 1–2개에서 같은 뱅크의 미사용 문항 약 5개를 풉니다. 시험 중에는 정답을 공개하지 않고, 연습 오답에서만 해설을 엽니다.
